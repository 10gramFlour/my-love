| Bereich | Dateiname |
| --- | --- |
| Foto in der Anfangssektion | `hero.png` |
| Erinnerung 1 | `memory-1.jpg` |
| Erinnerung 2 | `memory-2.jpg` |
| Erinnerung 3 | `memory-3.jpg` |

`JPG`, `JPEG`, `PNG` oder `WEBP` funktionieren grundsätzlich. Wenn du ein anderes Format benutzt, ändere die Endung auch in `src/data/loveStory.ts`, damit der Pfad wieder übereinstimmt. Für das beste Ergebnis verwende für `hero.png` ein hochkantiges Bild und für die Erinnerungen Bilder mit guter Auflösung.
